# Examentrainer Geschiedenis – VMBO

Eenvoudige PWA voor GitHub Pages. Eerste categorie: **Staatsinrichting**.

## Inhoud
- 86 bruikbare begrippen uit `staatsinrichtingapp.xlsx`.
- Antwoorden zijn niet hoofdlettergevoelig.
- Varianten gescheiden door `/` worden allemaal goed gerekend.
- Foute vragen komen terug in de oefenrij.
- Simpel puntensysteem: +10 goed, -2 fout (score kan niet onder 0).
- Voortgang en beheersing worden lokaal op het apparaat opgeslagen.
- Historisch uiterlijk en eigen SVG-logo.
- Docentcode als eenvoudige toestemmingsstap.

## GitHub Pages publiceren
1. Zet alle bestanden uit deze map in een nieuwe GitHub-repository.
2. Controleer in `config.js` de docentcode en wijzig die vóór publicatie.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch**, kies `main` en de map `/ (root)`.
5. Open de door GitHub gegeven Pages-link.

## Belangrijk over docenttoestemming
Dit is bewust een statische GitHub Pages-versie. De docentcode staat in de client en is dus technisch door leerlingen te achterhalen via de broncode. Dit is geschikt voor een eerste versie waarbij de docent de code uitdeelt, maar niet voor echte beveiligde accounts. Voor een echte schoolomgeving kan later een backend worden toegevoegd, bijvoorbeeld met Firebase/Supabase of een schoollogin.
